## 🎯 QUICK START (3 MINUTES)

### Step 1️⃣ Extract & Install
```bash
# Extract ZIP
unzip aerollerz-site-COMPLETE.zip
cd aerollerz-site

# Install dependencies
npm install --legacy-peer-deps
```

### Step 2️⃣ Add Your 53 Media Files
Copy to `public/media/`:
- 9 Instagram event photos
- 1 founder photo
- 29 service images
- 11 portfolio images
- 3 video files (MP4)

See `public/media/README.md` for exact names & sizes.

### Step 3️⃣ Test Locally
```bash
npm run dev
# Open http://localhost:3000
```

### Step 4️⃣ Deploy
```bash
npm run build
# Push to GitHub → Deploy via Vercel
```
